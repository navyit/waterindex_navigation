# Reference dataset: parallel processing of binary raster images 
# for water surface contour detection

## Description
Референсный набор данных параллельной обработки бинарных растровых изображений для нахождения контура водной поверхности
...

## Structure
- `data/raw/` — исходные снимки
- `data/processed/` — бинарные маски водной поверхности
- `code/` — скрипты обработки
